# 第一阶段实施记录

实施日期：2026-09-18。此记录区分代码完成情况和真实部署验收，不把替身测试作为外部服务已通过的证明。

## 已实现

- 注册、登录、退出、修改密码；用户名统一小写，密码 Argon2 哈希；随机登录凭证通过 HttpOnly Cookie 传递，MongoDB 仅保存凭证摘要。
- 每账号一个默认私有知识库。普通用户可以上传、查询、查看文档清单和下载自己的原文件；管理员无内容读取旁路，尚未加入第二阶段分享/成员权限。
- 聊天、任务、SSE、产品匹配、普通和 HyDE 检索都限定用户及知识库范围；传入模型前复核本地来源。
- 原文件和图片放入新私有桶，按库/文档/任务分开，访问经 `/assets/{id}` 校验归属。回答图片必须属于本轮已校验的本地来源文档；不直接展示外部图片。
- 文档同名替换以库为边界，新版本完整成功后才发布；失败不切换旧的可检索版本。配额预留和任务创建共用锁，失败释放新文档占位。
- 页面账户菜单、分账号聊天恢复、CSRF、401 清理、跨标签退出/账号切换及旧请求隔离。导入状态只影响当前账号；“终止上传”会取消本人仍在处理的导入任务，退出登录仍在账户菜单中。
- 本机账号管理，旧知识/聊天迁移预览、显式应用、归属冲突拒绝、中断恢复和条件回退。真实旧数据尚未迁移。

运行时仅新增 `pwdlib[argon2]`。`mongomock` 属于开发测试依赖，生产可用 `uv sync --locked --no-dev` 排除。

## 回答配图调整（2026-09-19）

输出前核验知识库权限和图片所属文档。图文 Markdown、图片白名单与来源一同写入会话，历史回放保留图片位置；送入下一轮模型前清理旧图片地址。前端在生成图片 HTML 前核对最终白名单，不执行模型输出的原始 HTML；流式过程中只显示文字，完成校验后原位显示图片。旧会话的底部附件保持兼容，正文已经展示的图片不重复追加。

## 启动和剩余部署验证

先对照 `.env.example` 补齐配置，然后：

```powershell
uv sync --locked
uv run uvicorn web.app:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000/login.html` 注册账号。旧数据默认不进入新账号的知识库；管理与迁移命令见 [运维与迁移](多用户运维与迁移.md)。

当前仍需在真实部署环境完成 MongoDB/Milvus/MinIO/MinerU/模型联调，使用两个普通账号和一个管理员上传同名不同内容文档，核对实际向量查询、私有对象匿名拒绝、图片引用、服务重启后的登录和清单恢复。迁移工具已通过替身测试，正式使用前仍需备份及在数据副本上试运行。

仅支持单 Web 实例、单 Uvicorn worker。任务不续跑；异常中断后释放配额，但存储故障可能留下不可检索的孤立资产/向量。尚无自动垃圾回收、文档删除、共享成员或分布式任务队列。
